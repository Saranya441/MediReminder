# MediReminder frontend

This React + Vite client is part of the full-stack MediReminder portfolio project. See the [root README](../README.md) for the feature overview, SQL Server setup, API instructions, Google sign-in configuration, and local run steps.

To start the frontend locally, run `npm ci`, copy `.env.example` to `.env.local`, then run `npm run dev`. Vite forwards `/api` requests to the backend at `http://localhost:5202` during development.
